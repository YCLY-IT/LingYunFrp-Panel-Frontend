## 注册页改为分步表单 (Register.vue)

- 需求：把注册流程拆步骤，并使用组件库（naive-ui）。
- 实现：用 `NSteps` / `NStep` 将注册拆为三步：
  1. 账户信息（username、nickname）
  2. 邮箱验证（email + emailCode，含人机验证后发码 + 60s 倒计时）
  3. 设置密码（password、confirmPassword + 服务条款/隐私政策链接）
- 关键点：按步骤校验用 `formRef.validate(callback, shouldRuleBeApplied)`，`shouldRuleBeApplied` 依赖 `FormItemRule.key`（已在每条 rule 上显式设置 key=字段名），通过 `stepFields` 映射筛选当前步字段。
- 保留原有逻辑：极验人机验证（GeetestService）、sendEmailCode 拼参、register 提交跳转 /login。
- 注意：编辑器 lint 对 Register.vue 报 `vue 没有导出成员 ref/computed/onMounted`（TS 2305），属 Volar 编辑后误报，与 Login.vue 等同写法无冲突，运行时/构建不受影响。

## 注册页底部留白修复（同日）

- 现象：Register 页面顶部 HomeMenu 下方只有上半屏有背景图，下半屏大面积白色留白。
- 根因：`.register` 仅 `display: flex` 无高度，元素高度≈内容高度；背景图通过内联 JS 设到 `.register` 上，故只覆盖内容区；AppContent 同时渲染 HomeMenu (64px) + RouterView，导致总高度 < 视口时下方露出 body 白色背景。
- 处理：
  1. `.register { min-height: calc(100vh - 64px); display: flex; }` — 正好填满 HomeMenu 之下的剩余视口，背景图覆盖全区域。
  2. `onMounted` 设 `document.body.style.overflowY = 'hidden'`，`onUnmounted` 恢复，避免滚动条闪烁。
  3. `.auth-card { max-height: calc(100vh - 64px - 40px); overflow-y: auto; }` — 长表单时卡片内部滚动而非溢出整页。
- 经验：项目里 Login.vue 已用同模式（`.login { height: 100vh }` + `body.overflowY: hidden`），新页面应保持一致。共享 scss 已有 `.auth-container { min-height: calc(100vh - 64px); ... }` 模板可复用。

## 注册页卡片圆角丢失修复（同日）

- 现象：`.auth-card` 已设 `border-radius: 16px`，但卡片四角仍是直角，圆角完全不可见。
- 根因：样式中存在 `.n-card { border-radius: 0px !important; }`（从 Login.vue 复制过来，登录页设计为直角），`!important` 优先级覆盖了 `.auth-card` 的圆角。
- 处理：删除该 `.n-card` 规则，`.auth-card` 的 16px 圆角即生效。
- 经验：跨页面复制样式时要核对设计意图；`!important` 是高风险信号，新页面避免直接套用。
